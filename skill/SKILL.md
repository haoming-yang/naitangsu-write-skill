# 现代言情写作方法库

本 skill 是对公开作品的创作方法归纳，不是作者本人，不代表作者发言，也不复现作品原文。输出时使用“本知识库归纳的方法”或“这类作品常见的写法”说明来源。

核心原则：用更干净的语言承载更具体的情感。规则是诊断信号，不是禁词表；最终服从题材、角色声音、叙事视角和场景功能。

## 何时使用

- 用户明确提到奶糖酥、奶糖酥作品研究、该知识库或类似风格。
- 用户处理现代青春、校园、小镇、都市、职场婚恋、豪门甜宠、娱乐圈言情。
- 用户要求分析或修改句子、段落、对话、情感线、章节钩子、简介、章名、番外或全书结构。

不因“写作”二字单独触发；古言、科幻、悬疑纯案件、非言情文本只提供通用叙事建议，不强套本库的情感公式。

## 执行总流程

1. 先判断任务：诊断、修改、起草、审读、题材适配或标题/章名设计。
2. 判断题材和风格档位：极净、平衡、松弛；用户指定时优先用户指定。
3. 先处理结构和关系功能，再处理段落节奏、句子和措辞。
4. 只读取当前任务需要的 reference，不加载完整资料库。
5. 输出具体位置、问题证据、修改方向；只有用户要求时才直接改全文。

## 题材适配

| 题材 | 优先观察 |
|---|---|
| 小镇青春 | 环境压迫、双向救赎、离开/成长/回返、物件与信件 |
| 职场婚恋 | 身份差、专业能力、公私边界、称呼变化、越界与克制 |
| 豪门/先婚后爱 | 契约关系、误会或失忆、日常兑现、公开确认 |
| 娱乐圈/保镖 | 公开身份、私下反差、媒体压力、身份揭示 |
| 快穿/双男主 | 任务结构、位面切换、固定情感主线、终局回收 |

需要题材规则时读取 `references/genre-adapters.md`。

## 风格档位

- **极净**：减少解释性心理和连续修辞，突出动作、物件、留白；适合校园慢热和酸涩文本。
- **平衡**：保留必要心理推演，控制重复解释；适合都市、职场和关系博弈。
- **松弛**：保留口语、语气词和适度重复；适合甜宠、日常和轻喜互动。

“觉得、仿佛、好像、忍不住、说、问、但是”等词只作为密度信号。先判断是否造成模板化、解释过度或角色失声，再决定是否修改。

## 工作流路由

- 用户说“帮我写/起草/写一章” → 读取 `novel-draft.md`。
- 用户说“修文/改文/润色/这段不对” → 读取 `novel-revise.md`。
- 用户说“审稿/终稿检查/检查全书” → 读取 `novel-review.md`。
- 用户问简介、书名、章名或章节钩子 → 读取 `references/title-and-chapter-hooks.md`。
- 用户问番外、配角线或 IF 线 → 读取 `references/extras-and-if-lines.md`。
- 用户问题材迁移 → 读取 `references/genre-adapters.md`。

## 输出边界

- 不以奶糖酥本人身份说话，不代作者发布声明，不捏造作者未公开的创作经历。
- 不复制作品原文、连续句式或可识别的角色关系；示例使用全新人物、场景和措辞。
- 不把统计倾向写成绝对规则，不为了“干净”破坏轻松口吻或角色个性。
- 不直接把作者账号、粉丝数、出版动态等资料当作写作方法。
