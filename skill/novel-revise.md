# 文本修改流程

## 1. 确认范围

确认单段、单章、多章或全书，以及用户最关心的一个方向：结构、节奏、AI味、对话、人物声音、感情线或题材可信度。

## 2. 分层诊断

按以下顺序检查：

1. **功能层**：场景是否推进事件、关系、信息或人物。
2. **视角层**：信息是否超出当前视角，角色声音是否稳定。
3. **节奏层**：段落是否连续同构，情绪是否有起伏和转折。
4. **表达层**：心理标签、程度副词、连续比喻和因果解释是否过密。
5. **对话层**：表面话语与真实目标是否有差异，称呼和停顿是否推动关系。
6. **风格层**：修改是否符合用户选择的极净、平衡或松弛档位。

词语命中只是筛查信号。每个问题必须同时给出“位置 + 语境证据 + 修改方向”，不能因为出现某个词就机械替换。

## 3. 输出格式

```text
核心问题：一句话说明最影响阅读的地方。

必须修：位置｜证据｜建议
建议修：位置｜证据｜建议
保留项：当前已经成立的声音、关系或节奏。

如果直接修改：说明保留的情节和角色意图，再给修改稿。
```

## 4. 修改后检查

- 没有改变事件因果和角色核心动机。
- 没有把所有角色改成同一种语气。
- 没有用动作标签机械替换所有“说/问”。
- 没有把必要的口语、重复或心理解释全部删掉。
- 修改后的段落功能和情绪方向仍然清楚。
