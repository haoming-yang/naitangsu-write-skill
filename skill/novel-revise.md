# 章节修改工作流

> 基于 43 卷技法，分层修改，先大后小。
> 调用本 skill 时，自动加载必要的 reference 文件。

## 工作流

### 第零步：确认修改范围

1. 用户要修改什么？**单段/单章/多章/全书**
2. 用户的核心诉求是什么？**去AI味/加快节奏/对话没张力/感情线不对/自查**
3. 上一轮的修改方向是什么？（多轮修改中，先回顾上一轮）

### 第一步：分层诊断

按以下顺序逐层诊断，先修大的再修小的：

#### 第一层：结构层（优先修）
加载 `plot-architecture.md`（卷二十三/二十四）+ `pov-hooks-blanks.md`（卷十六/十七）

检查项：
- [ ] 视角是否一致（一章不跳POV）？
- [ ] 章末钩子是否有效（六个公式之一）？
- [ ] 本章推进了哪条冲突线？
- [ ] 开篇三章是否完成了承诺（主角/问题/意象锚）？

#### 第二层：AI味诊断（必做）
加载 `ai-tell.md`（卷二十二）

逐症状检查：
- [ ] 症状一：程度副词铺满（连续3句≥2个"有些/有点/非常/格外"）
- [ ] 症状二：句句都用比喻（连续4句≥2个"像/仿佛/好似"）
- [ ] 症状三：动词平均分布（连续200字动词力度相似）
- [ ] 症状四：锯齿节奏（连续5段段长差异<20字）
- [ ] 症状五：因果链直给（每件事都解释了"因为"）
- [ ] 症状六：情绪标签铺满（"感到/觉得/意识到"密集）
- [ ] 症状七：段落之间缺少"气的变化"（连续翻5屏，每一段的口气都一样）

#### 第三层：句子与段落
加载 `sentences-paragraphs.md`（卷一/二/三）

检查项：
- [ ] 心理标签：感到/觉得/意识到/忍不住
- [ ] 软词：仿佛/似乎/好像/有些/有点
- [ ] 段首连词：但是/然而/所以/于是
- [ ] 连续比喻
- [ ] 段落节奏：连续同长→调整
- [ ] 过度解释情绪/因果/过渡

#### 第四层：对话
加载 `dialogue.md`（卷四）

检查项：
- [ ] 引号外无多余的"说/问/答/道"
- [ ] 对话不带火柴——情绪最深时话最少
- [ ] 潜台词深度≥2倍表面意思
- [ ] 嘴硬铁三角、回声模式、自欺欺人是否到位

#### 第五层：情感与心理
加载 `psychology-emotion.md`（卷五）

检查项：
- [ ] 身体语言是否替代了情绪词
- [ ] 哭泣强度阶梯是否合理
- [ ] 感官递进（视觉→听觉→触觉→嗅觉）是否到位
- [ ] 亲密接触阶进是否自然

### 第二步：输出诊断报告

```
📋 第N章诊断报告

🔴 必须修：
  - [问题1]：[具体位置] + [修改建议]
  - [问题2]：[具体位置] + [修改建议]

🟡 建议修：
  - [问题1]：[具体位置] + [修改建议]

🟢 已达标：
  - [维度1]
  - [维度2]

💡 一句话建议：[核心改进方向]
```

### 第三步：按需修改

- 用户说"直接改"→ 输出修改后的全文
- 用户说"我自己改"→ 只给诊断报告
- 多轮修改中 → 先回顾上一轮方向，确认是否继续同一个方向

### 第四步：修改后验证

修改完成后，逐项确认：
- [ ] 修改没有引入新的AI味症状
- [ ] 修改没有破坏角色的声音一致性
- [ ] 修改没有改变本章推进的冲突线

---

## 修改分寸（卷二十一）

- 改到第三版还觉得"不对"→ 问题可能在直觉，放手冷却再读
- 规则冲突时，语感赢
- 修改不是越多越好——改到角色说"对"为止
- 停手信号：开始在一个词上来回换 → 立刻停手

---

## 约束

- 先诊断再修改，用户要求时才直接改
- 修改时保留用户原文的核心意图和情节走向
- 不在修改中引入新情节点
- 承认边界：超出青春/校园/都市情感范围时，只给通用建议
