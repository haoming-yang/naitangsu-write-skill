# 故事记忆系统

> 这不是一个独立写作工具，而是一个**随写作进程自动更新的知识库**。
> 每次写完新章节后运行一次，保持角色、伏笔、时间线的一致性。

## 使用方式

用户写完一章后，说"更新故事记忆"，系统执行以下流程。

> ⚠️ `kb/` 目录建在**用户的小说项目目录**（当前工作目录），不是 skill 安装目录。  
> 知识库是项目数据，不应该混入技能文件。

---

## 第一步：读取当前知识库

读取 `kb/` 目录下的所有文件（如果存在）：
- `kb/characters.md` — 角色状态
- `kb/plot-threads.md` — 伏笔追踪
- `kb/timeline.md` — 时间线
- `kb/world.md` — 世界观/场景
- `kb/themes.md` — 主题/意象

如果 `kb/` 目录不存在，创建它并初始化空模板。

---

## 第二步：分析新章节，提取增量信息

从用户提供的新章节文本中提取以下信息：

### 2.1 角色状态变化
对每个已登记角色，检查：
- **外貌变化**：新伤疤？新发型？换了穿衣风格？
- **关系变化**：和谁的关系发生了质变（从陌生到熟悉、从朋友到暧昧、从信任到破裂）？
- **心理状态**：当前情绪基调是什么？有什么新的心理创伤或治愈？
- **技能/知识**：学会了什么新技能？知道了什么新信息？
- **位置变化**：当前在哪个城市/地点？

### 2.2 伏笔追踪
- **新埋的伏笔**：本章中有哪些未解释的异常、未兑现的承诺、未揭开的谜？
- **伏笔推进**：之前的伏笔在本章中是否有进展（部分揭示、线索增加）？
- **伏笔回收**：之前的伏笔是否在本章中完全解释？

### 2.3 时间线更新
- 本章发生在什么时间（日期/季节/相对于故事开始的时间）？
- 距离上一章过了多久？
- 本章内的关键事件时间节点

### 2.4 新信息
- 新登场的角色（姓名、身份、与主角的关系）
- 新出现的地点
- 新揭示的世界观规则

---

## 第三步：更新知识库文件

将提取的信息追加/更新到对应文件中。

### `kb/characters.md` 格式
```markdown
# 角色状态

## [角色名]
- **身份**：[一句话]
- **外貌特征**：[关键特征]
- **性格标签**：[3-5个词]
- **关系网络**：[与各角色的关系及当前状态]
- **当前状态**（最新章）：[位置/情绪/处境]
- **弧光进度**：[从X到Y，当前处于哪个阶段]
```

### `kb/plot-threads.md` 格式
```markdown
# 伏笔追踪

## 活跃伏笔
| ID | 内容 | 首次出现 | 最近进展 | 状态 |
|----|------|----------|----------|------|
| V001 | [具体内容] | 第X章 | 第Y章：[进展描述] | 进行中 |

## 已回收伏笔
| ID | 内容 | 首次出现 | 回收章节 | 回收方式 |
|----|------|----------|----------|----------|
```

### `kb/timeline.md` 格式
```markdown
# 时间线

## 第N章：[章节标题]
- **时间**：[日期/季节]
- **距上一章**：[X天/同时/紧接]
- **关键事件**：
  - [事件1]
  - [事件2]
```

### `kb/world.md` 格式
```markdown
# 世界观与场景

## 地点
- **[地点名]**：[描述] · 首次出现：第X章

## 规则
- **[规则]**：[描述] · 相关角色：[角色名]
```

### `kb/themes.md` 格式
```markdown
# 主题与意象

## 核心意象
- **[意象词]**（如雨/伞/光）：[当前状态] · 首次出现：第X章 · 最近出现：第Y章

## 主题命题
- **[命题句]**：[当前进展]
```

---

## 第四步：一致性检查

更新完成后，运行以下检查项：

1. **角色位置一致性**：同一时间段内角色不能同时在两个地方
2. **时间线连续性**：相邻章节之间的时间间隔是否合理
3. **伏笔健康度**：是否有超过20章未推进的活跃伏笔？（警告：可能已被遗忘）
4. **角色声音一致性**：角色的说话方式、行为模式是否与已建立的人设一致

如果有不一致，提醒用户。

---

## 第五步：输出更新摘要

```
📋 故事记忆更新完成（第N章）

🔄 角色变化：
  - [角色A]：[变化描述]
  - [角色B]：[变化描述]

🪝 伏笔动态：
  - 新增：[N]条
  - 推进：[N]条
  - 回收：[N]条

⏱ 时间线：第N章 → [日期]（距上一章X天）

⚠ 注意事项：
  - [如有不一致，在此列出]
```

## 初始化模板

当用户第一次使用（`kb/` 目录不存在）时，创建以下模板文件：

### `kb/characters.md`
```markdown
# 角色状态

> 每次写完新章节后更新。记录角色当前的状态、位置、关系变化。

---
```

### `kb/plot-threads.md`
```markdown
# 伏笔追踪

> 活跃伏笔：已埋下但未回收的线索。已回收伏笔：已完成的线索。

## 活跃伏笔

（暂无）

## 已回收伏笔

（暂无）
```

### `kb/timeline.md`
```markdown
# 时间线

> 按章节记录时间推进。注意检查时间连续性。

---
```

### `kb/world.md`
```markdown
# 世界观与场景

> 记录所有地点、规则、背景设定。

---
```

### `kb/themes.md`
```markdown
# 主题与意象

> 记录核心意象的演变轨迹和主题命题的推进。

---
```

---

## 约束

- 知识库是**增量更新**，不是每次重写
- 只记录**事实性信息**（已写进正文的内容），不记录计划中的内容
- 如果用户提供了多章，逐章处理
- 一致性检查只警告，不自动修改正文
