# 番外、配角线与 IF 线

## 番外的四种功能

1. **正文补缝**：补充缺失视角、时间段或未说出口的情绪。
2. **关系兑现**：展示正文承诺在日常生活中的落地。
3. **配角闭环**：给配角独立的目标、选择和情感结果。
4. **IF 线**：探索另一种选择，必须清楚标记为平行可能，不改写正文事实。

## 设计流程

先写清楚正文留下的空白，再决定番外功能；不要因为读者喜欢某角色就无目的延长。每个番外至少要新增一个信息、选择或关系状态，并完成自己的情绪闭环。

## 与正文的关系

- 正文负责主线因果和核心关系变化。
- 番外可以换视角、换节奏，但不能削弱正文结局。
- IF 线可以更甜、更轻或更大胆，但要保留“这是另一种可能”的边界。
- 配角番外不能只服务主角秀恩爱，应让配角完成自己的弧线。

## 终稿检查

- 番外是否补充了正文没有的信息？
- 是否出现重复正文的告白和冲突？
- 读者不看番外时，正文是否仍然完整？
- 读者看完番外时，是否获得新的情绪或理解？
