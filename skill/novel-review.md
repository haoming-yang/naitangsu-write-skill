# 终稿审读工作流

> 基于卷四十一终稿检查清单 + 分层审读体系，逐维度检查，输出结构化审读报告。
> 调用本 skill 时，自动加载所有必要的 reference 文件。

## 工作流

### 第零步：确认审读范围

1. **审读范围**：单章 / 多章 / 全书
2. **审读深度**：快速扫（只查🔴致命问题）/ 标准审（🔴+🟡）/ 深度审（全部维度）
3. **审读重点**：用户特别关心的维度（如只关心AI味/只关心感情线）

### 第一步：逐维度审读

按以下顺序检查，每层输出检查结果：

#### 1. 句子层面
加载 `sentences-paragraphs.md`（卷一/三）

| 检查项 | 标准 |
|--------|------|
| 心理标签 | 全文"感到/觉得/意识到/忍不住"→ 用身体反应替代 |
| 软词 | 全文"仿佛/好像/似乎"→ 用具体动作替代 |
| 形容词堆砌 | 一个名词前不超过1个"的" |
| 段首连词 | 段首无"但是/然而/所以/于是" |
| 感叹号 | 每章≤5个 |
| 破折号 | 不滥用，段落切换给空行，句子停顿给句号 |

#### 2. 段落层面
加载 `sentences-paragraphs.md`（卷二）

| 检查项 | 标准 |
|--------|------|
| 连续同长 | 不超过5段长度相似（差异<20字） |
| 情绪高点 | 跟短句连击 |
| 章节节奏 | 缓→蓄→爆→余韵四段推进 |
| 特殊段 | 名词独立段/动词独立段/情绪宣判短句独立段是否到位 |

#### 3. 对话层面
加载 `dialogue.md`（卷四）

| 检查项 | 标准 |
|--------|------|
| 引号外 | 无多余的"说/问/答/道" |
| 火柴 | 情绪最深时话最少 |
| 潜台词 | 深度≥2倍表面意思 |
| 嘴硬铁三角 | 行动先于语言+劣质借口+不直视 |
| 回声/自欺 | 有使用 |

#### 4. 视角层面
加载 `pov-hooks-blanks.md`（卷十六）

| 检查项 | 标准 |
|--------|------|
| 跨角色偷窥 | 无 |
| 上帝旁白 | 无（"多年后他会明白……"） |
| POV切换 | 一章不跳POV |
| 非视角角色 | 不写"觉得/感到" |

#### 5. 章节层面
加载 `pov-hooks-blanks.md`（卷十七）+ `narrative-system.md`（卷三十五）

| 检查项 | 标准 |
|--------|------|
| 章末钩子 | 六个公式之一 |
| 开篇三章 | 核心困境+双主角相遇+未完成画面 |
| 冲突线推进 | 每3-4章至少推进一条 |
| 无停滞线 | 没有连续5章停滞的叙事线 |
| 章节衔接 | 新章第一段回扣上一章的动作+情绪+意象 |

#### 6. AI味检测
加载 `ai-tell.md`（卷二十二）

| 检查项 | 标准 |
|--------|------|
| 七种症状 | 逐一扫描，标记出现位置 |
| 总体评分 | 1-10分（10=完全无AI味） |

#### 7. 感情线
加载 `sweet-pain-theme-ending.md`（卷二十七）+ `confession-arcs.md`（卷三十六/三十七/三十八）

| 检查项 | 标准 |
|--------|------|
| 甜虐比例 | 甜章埋虐种，虐章藏甜底 |
| 女主勇气 | 从L1走到了L4 |
| 男主克制 | 有对应的破防时刻 |
| 告白方式 | 贴合角色性格，非万用模板 |

#### 8. 全书闭环
加载 `sweet-pain-theme-ending.md`（卷二十八/二十九）+ `universal-model.md`（卷四十）

| 检查项 | 标准 |
|--------|------|
| 意象回环 | 第一章的意象在终章重现（双义翻新） |
| 物件闭环 | 贯穿全文的物件完成"入场→发展→闭环" |
| 空间释放 | 终章空间从密闭变为开阔 |
| 金句定调 | 不超过20字，不解释，只点一次 |
| 番外 | 有新信息+独立情感闭环 |

### 第三步：按需修改

- 用户要求修改 → 调用 novel-revise 工作流

---

## 约束

- 审读是诊断，不是修改。不要边审边改
- 评分是相对的——与用户自己的目标对齐，不是与"完美标准"对齐
- 打到80%就说明文本已经扎实了（卷四十一）
- 超出青春/校园/都市情感范围时，跳过题材专项检查
