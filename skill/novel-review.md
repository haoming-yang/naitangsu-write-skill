# 终稿审读流程

## 1. 确认审读范围

确认单章、多章或全书；快速扫、标准审或深度审；以及用户最关心的维度。

## 2. 审读维度

- 句子：具体、清楚、是否存在解释过密。
- 段落：长度和口气是否长期同构，情绪高点是否有变化。
- 对话：称呼、停顿、回避、反问和行动是否改变关系。
- 视角：是否出现非视角角色的内心或无来源信息。
- 章节：每章承担的功能、开头承诺、章间衔接和章末落点。
- 感情线：关系变化是否由事件和选择支撑，而不是只靠表白。
- 全书：意象、物件、承诺和主题是否得到回收。
- 题材可信度：职业、时代、行业设定是否达到用户需要的可信程度。

## 3. AI味诊断

只把以下内容当作筛查信号：程度副词密集、连续比喻、段落同构、情绪标签、因果解释过多、动词力度平均、语气长期不变。命中后必须检查语境，确认它是否真的导致模板化。

使用风险等级，不使用方向含混的“AI味指数”：

- 低：有局部信号，但不影响声音和阅读。
- 中：重复结构已经影响节奏或情绪传递。
- 高：文本高度模板化，角色声音和场景功能都被覆盖。

## 4. 输出格式

```text
审读范围：
总体判断：

高风险问题：位置｜证据｜影响｜建议
中风险问题：位置｜证据｜影响｜建议
低风险问题：位置｜建议
已成立部分：
下一步优先级：只列最重要的三项。
```

审读是诊断，不是修改。用户要求修改时，再读取 `novel-revise.md`。
