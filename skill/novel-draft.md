# 章节起草工作流

> 基于 43 卷技法，在起草阶段就避免常见问题。
> 调用本 skill 时，自动加载必要的 reference 文件。

## 工作流

### 第零步：确认上下文

在动笔之前，先确认以下信息（如果用户没提供，反问）：
1. **当前章节号**和**章节类型**（日常/转折/高潮/过渡/终章）
2. **本章视角角色**（有限第三人称，一章不跳POV）
3. **本章需要推进的冲突线**（关系线/秘密线/外部目标线，至少一条）
4. **上一章末尾的情绪**（本章开头需要回扣，见卷三十五.1）
5. **本章的节奏定位**（松/紧/缓→蓄→爆→余韵中的哪一段）

### 第一步：加载技法

根据章节类型，自动加载对应的 reference 文件：
- **所有章节** → `sentences-paragraphs.md`（卷一/二/三）+ `psychology-emotion.md`（卷五）
- **有对话场景** → 额外加载 `dialogue.md`（卷四）
- **有关键场景**（偶遇/电话/生病/送别/独处/进家）→ 额外加载 `scenes-revision.md`（卷二十）
- **章末需要钩子** → 额外加载 `pov-hooks-blanks.md`（卷十七）

### 第二步：起草

按以下顺序起草：

1. **开篇**（对应卷六.3）
   - 环境定调（1-2句）或动作切入（直接进入场景）
   - 回扣上一章末尾的情绪（卷三十五.1）
   - 给一个意象词（雨/光/风/路——对应卷四十.5）

2. **正文推进**
   - 句子：短句为主，句号分割动作（卷三.1/3.2）
   - 段落：多数1-2句，情绪累积时允许长段（卷二.1/2.2）
   - 对话：引号内只有对话，回答用动作（卷四.1/4.3）
   - 情绪：用身体反应替代心理标签（卷五.1/5.3）
   - 避免：感到/觉得/意识到/忍不住/仿佛/似乎（卷一·七条习惯）

3. **章末**（对应卷十七）
   - 从六个钩子公式中选一个：
     1. 未完成动作
     2. 未说出口的话
     3. 刚出现的变量
     4. 数字的变化
     5. 微小的反常
     6. 情绪断裂+时间跳跃

### 第三步：自查

起草完成后，逐项检查：
- [ ] 有没有"感到/觉得/意识到/忍不住"？（如有，用身体反应替换）
- [ ] 有没有连续3句以上出现比喻/仿佛/好像？（如有，只保留1个）
- [ ] 段首有没有"但是/然而/所以/于是"？（如有，删除）
- [ ] 有没有连续5段以上长度相似（差异<20字）？（如有，调整1-2段长度）
- [ ] 引号外有没有多余的"说/问/答/道"？（如有，用动作替代）
- [ ] 章末是否有钩子（六个公式之一）？
- [ ] 本章是否推进了至少一条冲突线？

### 第四步：输出

```
📝 第N章初稿

[正文]

---
📋 自查结果：
✅ 干净度：[通过/有N处需修改]
✅ 钩子：[公式X]
✅ 冲突线推进：[线名]
```

---

## 约束

- 不代笔写完整章节，除非用户明确说"帮我写"
- 用户说"帮我写"时，先完成第零步的所有确认，再动笔
- 起草过程中如果发现角色行为与已建立的人设冲突，提醒用户（参见 character-autonomy.md 卷四十三）
