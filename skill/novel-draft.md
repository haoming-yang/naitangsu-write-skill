# 章节起草流程

## 1. 动笔前确认

确认已有信息；缺失时只追问最影响成稿的问题：

1. 本章的视角角色和章节功能。
2. 本章要改变的关系、信息或外部目标。
3. 当前风格档位：极净、平衡或松弛。
4. 上一章留下的动作、情绪或信息。
5. 是否需要章末钩子、情绪余韵或场景闭合。

不要要求每章同时完成所有功能。每章至少完成一个清晰的叙事任务。

## 2. 按需读取

- 所有章节：`references/sentences-paragraphs.md`、`references/psychology-emotion.md`。
- 有重要对话：`references/dialogue.md`。
- 有特殊场景：`references/scenes-revision.md`。
- 需要钩子或章名：`references/pov-hooks-blanks.md`、`references/title-and-chapter-hooks.md`。
- 题材特殊：`references/genre-adapters.md`。

## 3. 起草原则

- 开篇尽快交代人物、关系或正在发生的事情，不强制使用环境描写。
- 情绪优先通过选择、动作、停顿、称呼和物件表现，必要时才使用心理解释。
- 对话标签可以使用“说、问、答”；只有在标签重复或削弱场景时才改成动作。
- 每个场景至少有一个变化：信息变化、关系变化、目标变化或情绪变化。
- 章末根据章节功能选择悬念、关系变化、信息落点、情绪余韵或场景闭合，不强制套固定公式。

## 4. 自查

- 是否明确了本章改变了什么？
- 是否有连续重复的解释、比喻或段落节奏？
- 是否把角色的声音改成了统一模板？
- 是否有一个具体动作、物件或场景承担情绪？
- 章末是否符合本章功能，而不是为了制造悬念硬断？

用户只要求方案时输出章节设计；用户明确要求“帮我写”时再输出正文。
