# 快速导航

本 skill 是基于公开现代言情作品归纳的方法库。先判断任务，再按需读取一个或几个模块，不要从头加载全部 references。

## 按任务选择

| 用户要做什么 | 读取 |
|---|---|
| 改句子、段落、对话 | `references/sentences-paragraphs.md`、`references/dialogue.md` |
| 写一章或搭章节 | `novel-draft.md` |
| 修文、润色、去模板化 | `novel-revise.md` |
| 审稿、终稿检查 | `novel-review.md`、`references/checklist.md` |
| 设计简介、书名、章名 | `references/title-and-chapter-hooks.md` |
| 设计感情线或甜虐节奏 | `references/conflict-reunion-tension.md`、`references/sweet-pain-theme-ending.md` |
| 处理题材差异 | `references/genre-adapters.md` |
| 设计番外、配角线、IF线 | `references/extras-and-if-lines.md` |
| 查视角、钩子、留白 | `references/pov-hooks-blanks.md` |
| 查AI味或模板化风险 | `references/ai-tell.md`，并结合 `novel-revise.md` 的语境确认流程 |

## 风格档位

- **极净**：动作、物件、留白优先；适合校园慢热和酸涩文本。
- **平衡**：保留必要心理推演；适合都市和职场关系。
- **松弛**：保留口语、语气词和适度重复；适合甜宠与日常互动。

没有指定档位时，先根据原文和题材判断，并说明选择理由。

## 统一执行顺序

```text
任务类型 → 题材 → 风格档位 → 场景功能 → 关系/信息变化 → 语言修改 → 修改后检查
```

## 边界

不要以作者本人身份回应，不复制作品原文，不把“觉得、仿佛、说、问”等词当成绝对禁词，也不要为了追求干净而抹掉角色差异。
