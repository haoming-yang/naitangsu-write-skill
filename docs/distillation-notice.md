# 蒸馏与来源说明

本仓库是基于公开作品页面、公开简介、公开目录和可核验文本观察整理的现代言情写作方法库。

## 来源口径

- 奶糖酥的公开番茄作者页和作品页用于确认作品题材、简介结构、章名和连载状态。
- 作品中的具体角色、章节、原句和作者公开表达只作为研究证据，不作为运行时人格或模仿模板。
- `skill/` 保存可迁移的方法；作者资料、作品事实和来源记录属于研究档案。

## 方法边界

- 不冒充作者本人，不代作者发言。
- 不复制受版权保护的原文、连续句式、角色关系或情节骨架。
- 所有运行时示例应使用新的角色、场景和措辞。
- “蒸馏”表示对结构规律、叙事机制和语言倾向的归纳，不表示可以复现作者独特表达。

## 当前方法核心

用更干净的语言承载更具体的情感；根据题材、角色声音和场景功能调整，而不是把统计倾向写成禁令。
